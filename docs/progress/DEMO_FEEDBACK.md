## 3. 데모의 한계 (버그 아님)

- **다이어그램·메일·동기화 로그 위젯은 비어 있음** — `demoClient.js` 가 `{ diagrams: [] }` /
  `{ emails: [] }` 를 준다. 실제 앱에선 백엔드·에이전트가 채운다.
- **데이터는 새로고침 시 초기화** — 인메모리. 영속은 실제 앱(SQLite)의 몫.
- **레이아웃만 `localStorage` 로 유지** — 브라우저별로 다르고, 시크릿 창에선 초기값.
- **반응형은 단일 `lg` 브레이크포인트** — 데스크톱 폭 기준. 좁은 화면 대응은 범위 밖.
- **로그인·다중 사용자 없음** — Phase E.
- 첫 배포 후 URL 이 CDN 에 퍼지는 데 1~2분 걸릴 수 있음.

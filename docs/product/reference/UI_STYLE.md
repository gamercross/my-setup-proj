# 🎨 UI/UX 참조 틀 (UI Style Reference) — v2

> 우리 대시보드의 **화면 골격·컴포넌트 패턴·시각 톤**이 따라갈 목표 틀.
> **v2 (2026-09-08):** 북극성을 인스타그램 릴스("Cowork", 다크 + 상단 탭)에서
> **"Confidency OS — Business Operations Platform"** 스타일(라이트 + 왼쪽 사이드바 + 부드러운 카드)로 교체.
> **기능·범위·진행도·제품 방향은 우리 로드맵 그대로**([PERSONAL_OS.md](../vision/PERSONAL_OS.md)) —
> 이 문서가 바꾸는 건 "어떻게 보이고 어떻게 조작되는가" 뿐이다. 이커머스 운영이라는 참조 화면의
> **목적 자체는 가져오지 않는다**([5장](#5-가져오지-않는-것)).
>
> ⚠️ 이 문서는 **계약이 아니라 방향**이다. 실제 화면 계약은 [UI_SPEC.md](UI_SPEC.md), 설계는 [../architecture/DESIGN.md](../architecture/DESIGN.md) §6.
> 코드·`UI_SPEC.md` 와 충돌하면 그쪽이 맞고 이 문서를 고친다.
> 사이드바 셸 + 주제별 위젯 레이아웃의 구조 결정은 [ADR-0032](../architecture/adr/ADR-0032-sidebar-shell-per-topic-layouts.md).

## 1. 북극성 (North Star)

- **출처:** 사용자 제시 스크린샷 "Confidency OS — Business Operations Platform" (Live Monitor 화면, 2026-09-08).
  캡처는 [`assets/ui-style/`](assets/ui-style/README.md) 참조.
- **한 줄:** *왼쪽 그룹형 사이드바 + 오프화이트 본문 + 부드러운 흰 카드(라운드 16, 옅은 그림자) + 차분한 파랑 강조 + 델타 칩이 붙은 스탯 타일 + 여백 큰 피드/테이블.*

참조 화면에서 **가져오는 것은 "틀"(레이아웃·컴포넌트·톤·밀도)** 이고,
**가져오지 않는 것은 "내용"(이커머스 운영 대시보드라는 목적, Live Funnel·Visitor Map·Order Queue 등 커머스 위젯)** 이다 → [5장](#5-가져오지-않는-것).
우리 본문은 그대로 **개인 생산성 OS**(할일·프로젝트·일정·브리핑·OKR·에이전트 활동·진행 현황)다.

### v1 → v2 무엇이 바뀌나

| 축 | v1 (Cowork) | v2 (Confidency OS 스타일) |
|---|---|---|
| 테마 | 다크 + 단일 보라 | **라이트 기본** (P3·[ADR-0027](../architecture/adr/ADR-0027-light-theme-default.md) 에서 이미 전환됨) |
| 네비게이션 | 상단 도메인 탭 바 | **왼쪽 사이드바** (그룹 헤더 + 아이콘 리스트 + 검색 + 하단 프로필) |
| 강조색 | 보라 `#7c6cf5` | **파랑 `#2f6feb` 유지** — 참조 화면은 보라지만 [ADR-0027](../architecture/adr/ADR-0027-light-theme-default.md) PO-2 결정(차분한 파랑)을 뒤집지 않는다 |
| 카드 | radius 10, 그림자 없음 | radius 16, `--shadow-card` (P4 에서 이미 반영) |
| 숫자 카드 | 레이블 + 큰 숫자 | **스탯 타일**: 아웃라인 아이콘 + 레이블 + 큰 값 + **델타 칩**(▲/▼ · `--ok`/`--bad`) + 보조 캡션 (P4 `StatTile` 확장) |
| 본문 배치 | 상단 카드 행 → 패널 | 동일하되 **주제별 위젯 셸** — 드래그/리사이즈/커스터마이즈 유지 |

│ 부제        │                                                           │
│ [🔍 검색 ⌘K]│  ┌─ 섹션 카드 ─────────┐ ┌─ 섹션 카드 ──┐ ┌─ 섹션 카드 ─┐ │
│            │  │ 섹션 타이틀    ⋯/링크 │ │ …            │ │ …           │ │

│            │  │ 컬럼   컬럼        컬럼            상태      액션        │ │
│ PLAN        │  │ …      …          …               ●pill     ⋯          │ │
│  ▸ OKR      │  └──────────────────────────────────────────────────────┘ │
│  ▸ 주간     │                                                           │
│ ──────────  │                                                           │
│ AGENT       │                                                           │
│  ▸ 활동     │                                                           │
│  ▸ 진행현황 │                                                           │

| 요소 | 규칙 |
|---|---|
| **사이드바** | 폭 고정(~240px), `--panel` 또는 살짝 다른 표면. 위→아래: **① 브랜드 블록**(라운드 사각 로고 + 앱 이름 + 한 줄 부제) → **② 검색 인풋**(`🔍 … ⌘K` 힌트, 지금은 표시만 가능) → **③ 그룹 네비**(그룹 헤더는 작은 대문자 뮤트 라벨, 그 아래 `아이콘 + 라벨` 항목) → **④ 하단 사용자 블록**(아바타 + 이름). 접기(rail 모드)는 후속. |
| **네비 그룹** | 그룹 = 우리 기능 축의 묶음. 초안: **COMMAND**(개요·할 일·브리핑), **PLAN**(OKR·주간 플래너), **AGENT**(에이전트 활동·진행 현황·다이어그램), **SYSTEM**(설정). 프로젝트·일정은 COMMAND 또는 별도. 최종 그룹핑은 [§4](#4-우리-기능--틀-매핑). |
| **활성 항목** | 옅은 회색 알약 배경(`--panel-2`) + 진한 텍스트 + (선택) 좌측 3px 파랑 인디케이터. 참조 화면과 동일하게 **강한 색 채움은 쓰지 않는다.** |
| **페이지 헤더** | 본문 최상단. 좌측: 작은 아이콘 + 화면 제목(H1) + 그 아래 한 줄 부제/컨텍스트. 우측: 상태 표시(`● Live` 알약, "N초마다 자동 새로고침" 캡션), 액션(새로고침·편집 모드 토글·아바타). |
| **본문** | 페이지 헤더 아래는 **주제별 위젯 셸** — `react-grid-layout` 그리드. 각 사이드바 항목이 자기 레이아웃을 가진다([ADR-0032](../architecture/adr/ADR-0032-sidebar-shell-per-topic-layouts.md)). 위젯 = 섹션 카드. |
| **섹션 카드 헤더** | 좌측: 작은 아이콘 + 섹션 타이틀. 우측: 액션 링크(`View All`) 또는 `⋯` 메뉴 또는 아이콘 버튼 1개. WidgetFrame 타이틀바(`⚙ ─ ✕`)와 통합. |
| **반응형** | 사이드바는 좁은 폭에서 오버레이/rail. 카드 그리드는 열 수 축소(lg/md/sm). 최소 800×600 ([UI_SPEC.md](UI_SPEC.md) §1). |

## 3. 컴포넌트 패턴 (재사용 규칙)

새 화면 요소는 아래 패턴 중 하나로 만든다. 새 패턴이 필요하면 이 표에 먼저 추가한다.

| # | 패턴 | 생김새 | 우리 쓰임새 | 상태 |
|---|---|---|---|---|
| P1 | **스탯 타일** | 카드. 위: 아웃라인 아이콘 + 작은 뮤트 레이블. 가운데: 큰 값. 아래: **델타 칩**(▲/▼ + %, 상승 `--ok`·하락 `--bad`) + 뮤트 캡션("vs 지난주"). tone: default·accent·ok·warn·bad | 미완료 할 일 수, 오늘 일정 수, 진행 중 프로젝트 수, OKR 평균 달성률, 에이전트 큐 대기 수, 마지막 sync 이후 경과 | ✅ P4 `StatTile` — **델타 칩 서브요소만 v2 에서 추가** |
| P2 | **원문 미리보기 패널** | 제목 + 스크롤 박스. 내용은 pre-wrap / monospace. 읽기 전용 + 복사 버튼 | Daily Brief 원문(`BriefCard`), 다이어그램 소스, 진행 현황 문서 본문 | ✅ D3 |
| P3 | **리스트 / 아코디언** | 항목마다 한 줄 요약. 좌/우에 **칩·배지**. 펼치면 상세. 행 높이는 여유 있게(참조 화면 피드처럼) | 할 일 목록, 프로젝트 목록, OKR key result 목록 | ✅ |
| P4 | **피드 / 테이블** | 뮤트 소문자 대문자 컬럼 헤더 → 여백 큰 행. 마지막 열은 상태 **알약**(색: `--ok`/`--accent-soft`/`--warn` 등) + `⋯` 액션. 카드 헤더 우측에 `View All` | 에이전트 활동 피드(sync/brief 이벤트), 주간 플래너 항목, 최근 완료 목록 | ⏳ v2 신규 |
| P5 | **칩 / 배지** | 알약형(radius 999). 상태(`todo`/`in_progress`/`done`), 우선순위(high/med/low), 카테고리 태그, 모델(opus/sonnet/haiku), `● Live` | 리스트·피드·카드 헤더에 부착. 색은 [디자인 토큰](#6-디자인-토큰-정합) 고정값만 | ✅ P4 `Chip` |
| P6 | **점-그리드 진행바** | N개 점 중 채워진 비율. `role="progressbar"` | 프로젝트 진행도, OKR 달성률 | ✅ P4 `DotProgress` |
| P7 | **미니 차트** | 인라인 SVG(PO-8 결정: Recharts 미도입). 스파크라인·간단 막대·퍼널형 실루엣. 강조색 `--accent` 그라디언트 | OKR 추세, 주간 완료 추세, 에이전트 실행 히스토리 | ⏳ (필요 시, `dataviz` 스킬) |
| P8 | **모달 폼** | 중앙 오버레이(portal). 제목 + 필드 + 하단 우측 `[취소][실행(파랑)]`. 토글 pill 그룹 | 할일/프로젝트 추가·편집, 위젯 피커, 위젯 설정 | ✅ C6 `WidgetSettings` |

**타이틀바(위젯 프레임):** 좌측 아이콘·이름, 우측 `⚙ 설정 · ─ 최소화 · ✕ 제거` ([UI_SPEC.md](UI_SPEC.md) §3.9 와 일치). 섹션 카드 헤더와 같은 자리를 쓴다.

## 4. 우리 기능 → 틀 매핑

사이드바 그룹은 **우리 기능 도메인**으로 채운다 (참조 화면의 COMMAND/COMMERCE/FINANCE/PLATFORM 대응).

| 그룹 | 사이드바 항목 | 화면 본문 (위젯 셸) | 상태 |
|---|---|---|---|
| **COMMAND** | 개요 | 스탯 타일 행(할일·일정·프로젝트·OKR) + 주요 위젯 요약 | 🚧 |
| | 할 일 | 할 일 위젯(P3 리스트 + P5 배지) · 칸반 뷰(P5) · 추가 폼(P8) | 🚧 (P5) |
| | 브리핑 | 오늘 브리핑 위젯(P2) | ✅ D3 |
| | 프로젝트 | 프로젝트 위젯(P3 + P6 진행바) | ✅ C2 |
| | 일정 | 오늘 일정 위젯(P3 리스트) | ✅ C3 |
| **PLAN** | OKR | OKR 대시보드(P1 스탯 타일 + P6 진행바 + P7 추세) · 주간 플래너(P4 피드) | ⏳ P8 |
| **AGENT** | 활동 | 에이전트 활동 위젯 — `sync_logs`/`health`/다음 실행(P1 + P4 피드) | ⏳ P7 |
| | 진행 현황 | 좌 폴더 트리 + 우 문서 본문(P2), mermaid 은 `DiagramPanel` 재사용 | ⏳ P9 |
| | 다이어그램 | 다이어그램 뷰어(내부 탭 + P2 소스 토글) | ✅ C4 |
| **SYSTEM** | 설정 | 전역 설정 · 테마 · 위젯 관리 | ⏳ |

> 각 항목은 **자기 위젯 레이아웃**을 갖고, 사용자가 위젯 추가/제거/이동/리사이즈/설정으로 커스터마이즈한다([ADR-0032](../architecture/adr/ADR-0032-sidebar-shell-per-topic-layouts.md), DO-2·DO-3 유지).
> 항목별 **기본 위젯 세트(초안 내용)** 는 우리가 채워 넣는다 — 빈 화면으로 시작하지 않는다.

## 5. 가져오지 않는 것

| 참조 화면 요소 | 왜 제외 |
|---|---|
| 이커머스 운영 목적 자체 (Order Queue·Pricing Engine·POS·Tax Engine·Marketplace) | 우리 제품은 **개인 생산성 OS**. 커머스 도메인은 범위 밖 ([PERSONAL_OS.md](../vision/PERSONAL_OS.md)) |
| Live Funnel · Visitor Locations 지도 · Live Order Feed | 커머스 전용 위젯. 우리는 할일·OKR·에이전트 피드로 대체 |
| 보라/퍼플 강조색 + 페이지 양 옆 보라 여백 | [ADR-0027](../architecture/adr/ADR-0027-light-theme-default.md) PO-2 = 차분한 파랑. 색만 우리 토큰으로 |
| "2초마다 자동 새로고침" 같은 초단위 실시간 폴링 | 우리 데이터는 그 정도 실시간이 아니다. 캡션 패턴만 차용(예: "5분마다"), 실제 폴링 주기는 위젯별 |
| 원격 기기 / 멀티 스토어 전환(`merchantos.store`) | 사용자 1명 제약 ([../vision/CONSTRAINTS.md](../vision/CONSTRAINTS.md) A-1) |
| 사이드바 항목 20개 규모 | 우리는 기능 도메인 수만큼(현재 ~10). 그룹으로 묶어 스크롤 최소화 |

## 6. 디자인 토큰 정합

**현재 코드 기준은 [UI_SPEC.md](UI_SPEC.md) §1 / `frontend/src/styles.css` `:root`** (P3·P4 반영 완료). 아래는 v2 에서 추가로 반영할 것.

| 이름 | 현재 | v2 | 비고 |
|---|---|---|---|
| `--bg` | `#f7f7f5` | 유지 | 본문 오프화이트 |
| `--panel` | `#ffffff` | 유지 | 카드 |
| `--panel-2` | `#f2f2ef` | 유지 | 사이드바 활성 알약·중첩 카드·헤더 |
| `--border` | `#ececec` | 유지 | 거의 안 보이는 경계 |
| `--accent` | `#2f6feb` | **유지 (파랑)** | 활성 인디케이터·`[실행]` 버튼·진행바·미니 차트. 참조 화면 보라는 안 씀 |
| `--card-radius` | `16px` | 유지 (P4) | |
| `--shadow-card` | 정의됨 (P4) | 유지 | 부드러운 1단 그림자 |
| `--sidebar-w` | (없음) | `240px` 신규 | 사이드바 폭 |
| `--sidebar-bg` | (없음) | `var(--panel)` 신규 | 필요 시 살짝 분리 |
| `--nav-active-bg` | (없음) | `var(--panel-2)` 신규 | 활성 항목 알약 |
| `--delta-up` / `--delta-down` | (없음) | `var(--ok)` / `var(--bad)` 별칭 | 스탯 델타 칩 |
| `--section-gap` | (없음) | `16px` 신규 | 카드 간 간격(참조 화면 밀도) |

> 다크 토큰은 `:root[data-theme='dark']` 에 **대칭 재정의만** 유지(전역 토글 UI 는 후속). 신규 토큰도 같은 규칙.

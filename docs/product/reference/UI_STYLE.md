# 🎨 UI/UX 참조 틀 (UI Style Reference)

> 우리 대시보드의 **화면 골격·컴포넌트 패턴·시각 톤**이 따라갈 목표 틀.
> 참조 대상은 인스타그램 릴스의 **"Claude 워크스페이스 대시보드"(이하 Cowork)** 화면이다.
> **기능·범위·진행도는 우리 로드맵 그대로** — 이 문서가 바꾸는 건 "어떻게 보이고 어떻게 조작되는가" 뿐이다.
>
> ⚠️ 이 문서는 **계약이 아니라 방향**이다. 실제 화면 계약은 [UI_SPEC.md](UI_SPEC.md), 설계는 [../architecture/DESIGN.md](../architecture/DESIGN.md) §6.
> 코드·`UI_SPEC.md` 와 충돌하면 그쪽이 맞고 이 문서를 고친다.

## 2. 레이아웃 골격

```
┌────────────────────────────────────────────────────────────────┐
│  ◆ 앱 이름            부제(도메인 나열)                  아바타   │  ← 헤더
├────────────────────────────────────────────────────────────────┤
│  ◇ 개요  · 할일 · 프로젝트 · 일정 · 브리핑 · 다이어그램 · 모니터  │  ← 도메인 탭 바
├────────────────────────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░  (전체 진행률 / 컨텍스트 바)      │  ← 얇은 상태 바
├────────────────────────────────────────────────────────────────┤
│  ┌─ 지표 ─┐ ┌─ 지표 ─┐ ┌─ 지표 ─┐ ┌─ 지표 ─┐   ← 숫자 카드 행   │
│  │  14   │ │  48   │ │  49   │ │   6   │                       │
│  └───────┘ └───────┘ └───────┘ └───────┘                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  본문 패널 (원문 미리보기 / 리스트 / 위젯 그리드)          │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| **헤더** | 좌측 앱 아이콘·이름, 그 아래 한 줄로 도메인 나열(부제). 우측 액션(새로고침·아바타) |
| **도메인 탭 바** | 탭 = 우리 기능 도메인 축(개요·할일·프로젝트·일정·브리핑·다이어그램·모니터). 아이콘 + 라벨. 활성 탭은 보라 pill 배경 |
| **상태 바** | 헤더 바로 아래 얇은 바 1개. "전체 진행률" 또는 현재 컨텍스트. 탭마다 의미가 달라도 위치·높이는 고정 |
| **본문** | 상단에 숫자 카드 행(선택) → 아래 패널 1~N개. **위젯 셸은 이 "본문" 안의 한 뷰**(개요 탭 또는 전용 탭)이지 별도 화면이 아니다 |
| **반응형** | 카드 행은 wrap, 본문 패널은 1열로 접힘. 최소 800×600 ([UI_SPEC.md](UI_SPEC.md) §1) |

## 3. 컴포넌트 패턴 (재사용 규칙)

새 화면 요소는 아래 6개 패턴 중 하나로 만든다. 새 패턴이 필요하면 이 표에 먼저 추가한다.

| # | 패턴 | 생김새 | 우리 쓰임새 |
|---|---|---|---|
| P1 | **숫자 카드** | 둥근 카드. 위: 작은 회색 레이블. 아래: 큰 숫자(강조색). 카드 여러 개를 한 행에 균등 배치 | 할일 미완료 수, 오늘 일정 수, 진행 중 프로젝트 수, 에이전트 큐 대기 수 |
| P2 | **원문 미리보기 패널** | 제목 + 스크롤 박스. 내용은 monospace, 구문 강조. 읽기 전용 | Daily Brief 원문, 다이어그램 소스, `CLAUDE.md`/설정 미리보기(관리 화면 만들면) |
| P3 | **아코디언 리스트** | 항목마다 한 줄 요약 + 우측 ▽. 펼치면 상세. 항목 좌측/우측에 **배지** | 할일 목록(상태 배지), 에이전트 큐(모델·상태 배지), 프로젝트 목록 |
| P4 | **배지** | 알약형(radius 999). 종류: 상태(`todo`/`in_progress`/`done`), 우선순위(high/med/low), 모델(opus/sonnet/haiku), 범위 | 리스트 항목·카드 헤더에 부착. 색은 [디자인 토큰](#6-디자인-토큰-정합) 고정값만 |
| P5 | **모니터 카드** | 숫자 카드의 변형. 레이블 + 값(버전/상태 문자열) + 보조 메타(PID·CPU·MEM) | 모니터 탭: CLI 버전, 활성 세션 수, 각 세션 리소스 ([ADR-0013](../architecture/adr/ADR-0013-dashboard-agent-queue.md)) |
| P6 | **모달 폼** | 중앙 오버레이. 제목 + 필드 + 하단 우측 [취소][실행(보라)]. 범위 선택은 토글 pill 그룹 | 할일/프로젝트 추가·편집, 위젯 추가 피커, 위젯 설정 |

**타이틀바(위젯 프레임):** 좌측 아이콘·이름, 우측 `⚙ 설정 · ─ 최소화 · ✕ 제거` ([UI_SPEC.md](UI_SPEC.md) §3.9 와 일치).

## 4. 우리 기능 → 틀 매핑

| 우리 기능 (FR) | 배치 | 차용 패턴 | 상태 |
|---|---|---|---|
| 개요 탭 (FR-UI-01) | 도메인 탭 첫 번째 | P1 숫자 카드 행 + 주요 위젯 요약 | 🚧 |
| 할일 위젯 (FR-TASK-*, FR-UI-01) | 본문 패널 / 위젯 | P3 아코디언 + P4 상태·우선순위 배지, P6 추가 폼 | 🚧 |
| 프로젝트 위젯 (FR-PROJ-*) | 본문 패널 / 위젯 | P3 리스트 + 진행도 바(강조색) + P4 상태 배지 | 🚧 |
| 오늘 일정 위젯 (FR-UI-01, W5/C3) | 위젯 | P3 리스트(시간 + 제목) | ⏳ |
| 오늘 브리핑 카드 (W7/D) | 위젯 | P2 원문 미리보기 패널 | ⏳ |
| 다이어그램 뷰어 (FR-UI-05) | 전용 탭 또는 위젯 | 본문 풀폭 뷰 + 내부 탭(아키텍처·로드맵·진행) + P2 소스 토글 | ⏳ (제안) |
| 에이전트 큐 / 모니터 (ADR-0013) | "모니터" 탭 | P5 모니터 카드 + P3 리스트(P4 모델 배지) | ⏳ |
| 위젯 셸 (FR-WIDGET-01~08) | 개요/전용 탭 본문 | 본문 = `react-grid-layout` 그리드, 위젯 = 카드, 타이틀바 `⚙ ─ ✕` | ⏳ (C5) |
| 위젯별 테마 (FR-WIDGET-05) | 위젯 ⚙ → P6 모달 | 프리셋: **다크·보라 기본** + 색·모서리·밀도·타이틀바 조정 | ⏳ (C6) |
| 오류 상태 (FR-UI-04, FR-WIDGET-07) | 각 위젯/셸 바 아래 | ErrorBanner (틀의 톤 유지: 카드형, 경고색) | ⏳ |

> "능력 맵"(Cowork 의 지침↔스킬↔에이전트 관계 그래프)은 우리 요구사항에 **아직 없음**. FR 후보로만 메모 — 도입 시 다이어그램 뷰어(FR-UI-05)의 한 뷰로 붙이는 것을 우선 검토.

## 5. 가져오지 않는 것

| Cowork 요소 | 왜 제외 |
|---|---|
| 픽셀아트 RPG "사무실" 뷰 (에이전트 = 캐릭터) | 구현 비용 대비 가치 불명확. 모니터 탭은 P5 카드 + P3 리스트로 충분. 재미 요소는 나중에 별도 검토 |
| 지침·스킬·커넥터·훅·플러그인 관리 탭 | Claude Code 셋업 관리 = 우리 제품 목적이 아님 (우리는 개인 생산성 대시보드) |
| CLAUDE.md 템플릿 생성기 / 폴더 구조 생성 | 위와 동일 |
| 원격 기기 등록 | 범위 밖 ([../vision/CONSTRAINTS.md](../vision/CONSTRAINTS.md) A-1: 사용자 1명) |
| 상단 탭 12개 규모 | 우리는 기능 도메인 수만큼(현재 6~7개). 탭 과잉 방지 |

## 6. 디자인 토큰 정합

Cowork 톤(다크 + 보라)을 우리 토큰에 반영한다. **현재 코드 기준은 [UI_SPEC.md](UI_SPEC.md) §1** 이며, 아래는 그쪽으로 반영할 제안이다.

| 이름 | 현재 ([UI_SPEC.md](UI_SPEC.md) §1) | 제안 (Cowork 정합) | 비고 |
|---|---|---|---|
| `--bg` | `#0f172a` | 유지 | 이미 다크 |
| `--panel` | `#1e293b` | 유지 | 카드 배경 |
| `--accent` | `#f59e0b` (앰버) | `#7c6cf5` 계열 (보라) 로 전환 검토 | Cowork 의 핵심 강조색. 진행도 바·활성 탭·[실행] 버튼 |
| 활성 탭 배경 | (없음) | `--accent` 투명도 낮춘 pill | P4/탭 바 |
| 카드 radius | `10px` | `12px` | Cowork 이 약간 더 둥긂 |
| 배지 radius | `999px` | 유지 | |
| 밀도 | (단일) | `comfortable` / `compact` 2단 ([ADR-0022](../architecture/adr/ADR-0022-per-widget-theming.md)) | 위젯 config |

> `--accent` 를 앰버→보라로 바꾸면 우선순위 배지(high `#ef4444`, medium 이 현재 `--accent` 재사용)와 충돌한다.
> medium 우선순위 전용 색을 따로 정의한 뒤 `--accent` 를 옮겨야 한다. C6 토큰 승격 작업에서 함께 처리.

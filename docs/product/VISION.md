## 핵심 기능 (우선순위 순)

1. **오늘/내일 할 일 정리** — 아침에 자동 브리핑 생성
2. **프로젝트 진행도 추적** — Notion 연동
3. **이메일 통합 관리** — 여러 계정을 한 화면에서
4. **캘린더 일정 확인** — 실시간 동기화

# ⚠️ 리스크 레지스터 (Risk Register)

> 무엇이 틀어질 수 있고, 어떻게 대비하는가. 제약·가정은 [CONSTRAINTS.md](CONSTRAINTS.md), 갭은 [AS_IS.md](AS_IS.md) §4.
> 갭(G)이 "지금 있는 차이"라면 리스크(R)는 "앞으로 생길 수 있는 문제"다.

## 척도

- **확률**: 낮음 / 중간 / 높음
- **영향**: 낮음(우회 가능) / 중간(일정 며칠) / 높음(범위·마감 위협)
- **등급** = 확률 × 영향 → 🔴 높음 · 🟠 중간 · 🟡 낮음
- 상태: 🟢 대비됨 · 🟡 감시 · 🔴 미대응
